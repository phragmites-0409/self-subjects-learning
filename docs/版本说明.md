# 版本与运行环境

- `subjects-learning-2`：正式本地识别版，端口 8000，根目录启停入口调用本版。
- `subjects-learning-1`：外部 AI 旧版，端口 8001，使用自己的启停入口。
- 两版数据独立；原有数据库、图片、备份和历史归档保留。
- 2026-10-24：OCR 相关运行库、Python 和模型从外部运行目录复制到根目录 `runtimes/`，逐文件核验后切换路径；源目录保留作回退。
- `runtime.json` 统一配置运行目录；各版 `version.json` 仅配置版本、识别方式和端口。
- GitHub 使用源码、依赖锁文件和模型来源清单；`runtimes/`、私人数据与历史快照不纳入 Git。

详细内容见 [安装说明](INSTALL.md) 和 [迁移验收](MIGRATION-2026-10-24.md)。
