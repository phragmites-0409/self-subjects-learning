# 题图处理验证与建议

验证日期：2026-10-12。正式应用在 `127.0.0.1:8000` 保持原配置；所有修改题目、入库和出卷测试均使用 D 盘隔离数据库。

## 结论

本地拍题、整页照片/扫描 PDF/文字 PDF 答案索引与裁切可用；题图清理目前仍是辅助整理，不能等同于无笔迹的可靠打印稿。

建议流程：图块与选项关系校对 → 保守去色与亮度增强 → 重叠笔迹局部复核 → 选定打印稿。严重遮挡优先使用同版本干净原 PDF 或照片，简单线图可辅助重绘并核对结构。

本次没有修改正式应用代码、配置、数据库或用户题图。仅新增离线试验、验证和报告脚本。复用已有库，新增安装为零；实验材料保存在 D 盘。

## 图像对比

试验了现有去色、扩大相邻红色像素掩膜、局部修复、局部亮度校正、灰度增强、黑白阈值，以及人工校对的图块拆分。

- 去色＋亮度增强使图更清晰，但黑色圈选和箭头依然存在，透印也未完全消失。
- 将图形与可重新排版的 A—D 标签分开，可以避开 B 标签周围的圈选及页面旁边的答案提示。裁框与选项关系在本样本上人工核对，不能声称通用自动匹配已解决。
- 局部修复候选人工擦除了主图铅笔箭头，并依据可见端点补画约 35 像素横轴；其他波形沿用照片。候选仍有透印，须核对后使用。
- 合成样本用 13 像素红笔覆盖 3 像素印刷曲线。重叠区域原黑色像素召回：现有修复 53.49%，扩大掩膜后 38.60%。整体召回高会掩盖局部损失。该指标是固定阈值下的合成像素对照，不是实际照片还原率。

不建议默认全图强二值化、删除小连通域或形态学开运算，避免丢失细线、虚线、下标、箭头和连接点。题图原本带颜色时，需要关闭全图去色或仅处理确认的笔迹区域。

## 接入优先级

1. 将图块坐标、选项编号、匹配关系分别保存；漏图或关系不明时提示复核。
2. 在处理副本上支持多框裁切及人工笔迹掩膜，保留原件和局部回退能力，解决一裁图就恢复笔迹的问题。
3. 最终打印图独立保存；重排过的图形选项不再重复打印空标签。图像的核对不要求重新确认已由人工提供的答案。
4. 重叠笔迹进入复核；波形、几何、电路可辅助 SVG 重绘，必须核对实虚线、连接与标注。化学结构、依赖精确测量的图优先干净来源。
5. 修复中文换行与内嵌公式的兼容问题、下标字体和分页留白。不要把模板排版失败误认为识图失败。

LaMa 等本地修复模型可作为背景修复的后续试验，但本次没有安装或测试其效果。模型仍需要区域掩膜；生成合理内容不能证明恢复真实曲线、刻度或连接关系，因此不作为默认自动还原方案。
